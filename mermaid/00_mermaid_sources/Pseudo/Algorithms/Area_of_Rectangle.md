## 7. Calculate Area of a Rectangle

Create an algorithm and flowchart to input length and width, calculate the area (**Area = Length × Width**), and display the result.

---

### ✔ Pseudocode

```text

START

        INPUT Length, Width

        Area = Length * Width

        PRINT Area

End

```

### ✔ Flowchart

```mermaid

flowchart TD
    A(["Start"]) --> B[/Input length and width/]
    B --> C["Calculate Area = length * width"]
    C --> D[/Display Area/]
    D --> E(["End"])

```
